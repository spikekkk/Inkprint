# 设置页信息架构设计

日期：2026-11-14  
状态：用户已确认分组方向，待审核完整设计稿  
范围：日记插件设置页的内容分组、默认行为、响应式入口与数据保存

## 目标

- 让设置页只处理影响插件行为的配置。
- 让用户能明确知道每条记录会写到哪里、图片保存在哪里、目标进度如何计算。
- 保持默认配置可直接使用，减少首次安装时的必填项。
- 桌面端和移动端都可进入同一套设置，不维护两份配置。
- 常用设置默认可见，高级维护功能默认收起。

## 非目标

- 在设置页中管理具体日记、书籍、长文或标签内容。
- 在设置页中提供搜索功能。
- 用设置页替代 Obsidian 自带的主题、字体、附件和快捷键设置。
- 在首版中提供任意字段级自定义模板编辑器。
- 将页面变成带账号、云服务或同步服务的“我的”页面。

## 设置入口

### 桌面端

- 入口位于日记插件左侧栏底部。
- 点击后在主区域内打开居中的设置面板。
- 用户可以继续看到侧栏和当前上下文，不需要重新打开工作区。

### 移动端

- 入口位于左侧抽屉底部。
- 点击后打开全屏设置页，顶部提供关闭按钮。
- 关闭后回到进入设置前的位置和滚动状态。

## 默认可见分组

### 通用配置：日记与存储

该组位于设置页最上方，不显示分组标题，遵循 Obsidian Style Guide。

| 设置项 | 默认行为 |
| --- | --- |
| 日记目录 | 优先读取 Obsidian Daily Notes 配置；允许覆盖 |
| 日记写入标题 | `## 记录` |
| 日记模板 | `Template/Daily.md`，可为空 |
| 书籍目录 | `Books` |
| 长文目录 | `Longform` |
| 模板目录 | `Template` |

规则：

- 路径使用 Vault 相对路径。
- 所有路径在保存前执行 `normalizePath()`。
- 不存在的目录在首次使用时创建，不静默改写用户已有目录。
- 如果 Daily Notes 的目录发生变化，插件提示用户是否同步更新。

### 写作

| 设置项 | 默认行为 |
| --- | --- |
| 保存快捷键 | `Cmd/Ctrl + Enter` |
| 保存后保留焦点 | 开启 |
| 附件目录 | 跟随 Obsidian 附件设置 |
| 图片展示 | 缩略图预览 |
| 标签选择器 | 显示最近使用、常用标签和搜索 |
| 自动标签建议 | 开启 |
| 自动应用低风险标签 | 关闭 |

规则：

- 动作标签、目标归属和完成状态不会在没有确认时自动应用。
- 标签选择器只从已有 Diary 标签和 frontmatter 标签生成候选。
- 图片插入失败时保留正文，不阻止用户继续写作。

### 打卡与目标

| 设置项 | 默认行为 |
| --- | --- |
| 首页快捷打卡数 | 3 |
| 每周起始日 | 周一 |
| 完成项自动折叠 | 开启 |
| 目标进度 | 根据已确认完成记录自动计算 |
| 一次性任务完成后归档 | 开启 |
| 默认打卡模板 | 为空，可由用户添加 |

规则：

- 设置页只定义默认打卡与计算规则，不直接修改历史记录。
- 修改默认打卡模板从下一天开始使用。
- 修改目标进度模式时需要提示是否重算历史数据。
- 跨月、跨周目标继续使用实际起止日期，不按自然月强行切割。

### 外观

| 设置项 | 默认行为 |
| --- | --- |
| 强调色 | 跟随 Obsidian |
| 可选强调色 | 薄荷、自定义 |
| 间距 | 舒适 |
| 热力图指标 | 写作字数 |
| 手机菜单按钮 | 左下角 |
| 侧栏统计摘要 | 显示 |

规则：

- 默认读取 Obsidian 主题与强调色。
- 自定义颜色只作用于插件根容器，不覆盖全局主题变量。
- 明暗模式颜色必须分别验证可读性。
- 图片缩略图处理不得影响正文中的原图查看。

## 高级分组

高级默认折叠，包含：

- 重建内容索引。
- 配置不参与统计的排除目录。
- 导出插件设置副本。
- 清理无效草稿。
- 调试日志开关。
- 修复损坏的 `journal-meta` 元数据。

高级操作规则：

- “重建索引”只读取 Markdown，不修改正文。
- “清理草稿”必须展示数量并二次确认。
- “导出设置”只导出配置，不导出日记内容。
- 调试日志默认关闭，且不得记录正文或私密路径内容。

## 保存机制

- 设置项修改后立即保存，不设置额外的全局“保存”按钮。
- 文本输入使用短暂防抖；开关、选择和颜色修改立即提交。
- 每次提交显示“已保存”状态，失败时显示可重试错误。
- 保存失败时保留界面中的新值，直到用户离开或重试。
- 插件数据保存在 Obsidian 插件数据文件中，不写入 Diary 正文。

## 验证与错误处理

- 目录与模板路径必须是 Vault 内路径。
- 模板文件不存在时禁止保存该路径，并保留旧值。
- 日记目录与书籍目录不允许相同。
- 长文目录可以与日记目录不同；若相同，搜索结果仍按 `type` 区分。
- 自定义颜色必须是有效颜色值。
- 设置版本升级时执行显式迁移，不静默丢弃未知字段。

## 响应式与可访问性

- 桌面设置面板和移动设置页使用同一设置组件与保存逻辑。
- 所有设置项使用原生输入控件，并带可见标签。
- 分组标题可被屏幕阅读器识别。
- 移动端有效触控区域不小于 44px。
- 关闭设置后焦点返回原设置入口。

## 验收标准

- 用户能在桌面和手机端进入同一套设置。
- 修改路径后，新记录写入正确位置，旧记录不被移动。
- 默认仅显示四个常用分组，高级设置默认收起。
- 设置修改立即保存，并有明确成功或失败状态。
- 自动标签建议默认开启，但不会自动完成目标任务。
- 热力图指标、菜单位置和强调色可以独立配置。
- 索引和草稿相关高级操作不会修改或删除 Markdown 正文。
